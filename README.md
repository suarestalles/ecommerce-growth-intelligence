# E-commerce Growth Intelligence

An analytics platform for e-commerce performance, customer
intelligence, and data-driven business decisions.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQL
- Next.js
- TypeScript
- Docker

## Project Structure

- `backend/`: API and business logic
- `frontend/`: web dashboard
- `data/`: local datasets (not committed)
- `sql/`: analytical transformations and queries
- `scripts/`: data ingestion utilities
- `docs/`: project documentation

## Development Status

Initial project setup.

## Getting Started

Backend and frontend setup instructions will be documented
as the implementation progresses.

## Data Sources

The project will initially use the public Olist Brazilian
E-Commerce dataset from Kaggle.
